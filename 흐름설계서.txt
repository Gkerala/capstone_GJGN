# 전체 앱 구조 요약 (End-to-End Flow)
    (카카오 로그인 → JWT 인증 → 프로필 등록 → 메인 기능 → 기록/분석/마이페이지)

    1. 앱 최초 실행
        📌 상황 A — 첫 설치 후 첫 실행

            앱 실행

            사용자 기기에 저장된 JWT 토큰 없음

            → LoginActivity 진입
    2. 카카오 로그인 과정 (첫 로그인)

        사용자가 카카오 버튼 클릭

        Kakao SDK → 카카오 토큰 발급

        앱이 카카오 토큰을 서버에 전달

            POST /api/auth/login/kakao/

        Django 서버 로직

            카카오 토큰 검증

            해당 카카오 ID를 가진 User 조회

                없으면 → 새 User 생성

                있으면 → 기존 User 반환

            JWT Access / Refresh 발급

            응답 JSON:

                {
                "access": "...",
                "refresh": "...",
                "is_new_user": true/false,
                "is_profile_complete": true/false
                }


            앱은 JWT 토큰을 로컬에 저장(SharedPreferences)
    3. 로그인 이후 흐름 분기

        서버 응답에 따라 동작이 갈린다.

        ✔ Case 1 — 신규 사용자 + 프로필 미완성

            is_new_user = true

            is_profile_complete = false

            👉 ProfileSetupActivity(1~6단계)로 이동

        ✔ Case 2 — 기존 사용자지만 프로필 미완성

            예: 탈퇴 후 재가입? / 초기 계정인데 정보 없음

            is_profile_complete = false

            👉 ProfileSetupActivity로 이동

        ✔ Case 3 — 프로필 이미 완성된 사용자

            is_profile_complete = true

            👉 MainActivity로 바로 이동
    4. 앱 재접속 시 흐름 (자동로그인)

        앱 실행 시:

            SharedPreferences에서 JWT Access Token 확인

            있으면 /api/users/me/ GET 요청

            응답 정상 → 자동 로그인 성공

            바로 MainActivity 진입

        ###⚠ Access Token 만료 시?

            Refresh Token으로 재발급 요청 → 자동 갱신

            Refresh마저 만료 → LoginActivity로 이동
    5. 프로필 설정 ProfileSetupActivity (1~6단계)
        1단계: 성별 선택

            GenderFragment

        2단계: 생년월일 선택

            BirthFragment

        3단계: 키·몸무게 입력 (소수점 포함 NumberPicker)

            BodyFragment

        4단계: 목표 체중 입력 (소수점 포함 NumberPicker)

            TargetWeightFragment

        5단계: 활동량 및 목표 (감량/유지/증가)

            ActivityGoalFragment

        6단계: 입력 정보 요약 확인

            SummaryFragment

            “완료” 클릭 → 서버 저장

            PUT /api/users/me/

            PATCH /api/users/me/goal/

        완료 후 → MainActivity로 이동
    6. 메인 화면(MainActivity)

        앱의 중심 허브 역할.

        구성 요소

            오늘 먹은 총 칼로리

            남은 목표 칼로리

            최근 체중 변화

            식단 기록하기 버튼

            체중 기록하기 버튼

        사용 API

            /api/records/today/

            /api/weights/recent/
    7. 식단 기록(RecordActivity)

        사용 흐름:

            사진 촬영 / 갤러리 선택

            서버에 이미지 업로드

                POST /api/records/upload/

            Django → YOLO 모델 실행하여

                음식 객체 검출

                분량 계산

                칼로리 추정

            앱으로 결과 반환

            사용자는 아침/점심/저녁 선택

            DB에 MealRecord 저장
    8. 영양 분석 / 기록 분석 (AnalysisActivity)

        최근 1~2주 식단 및 체중 분석

        꺾은선 그래프, 바 그래프 표시

        API:

            /api/analysis/weekly/
    9. 내 정보 (MyPageActivity)
        구성

            내 프로필 조회 (/api/users/me/)

            프로필 수정 (/api/users/me/ PUT)

            목표 수정 (/api/users/me/goal/ PATCH)

            체중 기록 확인

            로그아웃

            회원탈퇴
    10. 로그아웃 & 회원탈퇴
        로그아웃

            JWT local 삭제

            메인 → LoginActivity

        회원탈퇴

            DELETE /api/auth/delete/

            서버에서 User 삭제

            local JWT 삭제

            LoginActivity 돌아감
#전체 데이터 흐름 요약 (최종 그림)
    [앱 최초 실행]
        ↓
    [카카오 로그인]
        ↓
    [Django: 카카오 검증 → JWT 발급]
        ↓
    [앱: JWT 저장]
        ↓ 분기
    ---------------------------------------
    1) 프로필 미완성 → ProfileSetup 1~6단계
            ↓ 저장
            → MainActivity
    ---------------------------------------
    2) 프로필 완성 사용자 → MainActivity 바로 진입
    ---------------------------------------
    [메인 페이지]
    ↓      ↓          ↓
    식단기록   체중기록   분석페이지
    ↓
    YOLO 분석
    ↓
    DB 저장
    ---------------------------------------
    [내 정보 페이지]
    프로필 수정 / 목표 수정 / 로그아웃 / 탈퇴
    ---------------------------------------
